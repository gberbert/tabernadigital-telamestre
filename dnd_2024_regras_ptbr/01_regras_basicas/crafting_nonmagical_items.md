# Criação de itens não mágicos

Para criar um item não mágico, você precisa de ferramentas, matéria-prima e tempo, cada um dos quais é detalhado abaixo. Se você
            atender aos requisitos, você fabrica o item e pode usá-lo ou vendê-lo pelo preço normal.


### Ferramentas

A seção “Ferramentas” deste capítulo lista quais ferramentas são necessárias para fazer determinados itens. O DM atribui o necessário
            ferramentas para itens não listados lá.

Você deve usar a ferramenta necessária para fazer um item e ter proficiência com essa ferramenta. Qualquer pessoa que o ajude deve
            também tem proficiência com isso.


### Matérias-primas

Para fazer um item, você precisa de matéria-prima que vale metade do seu custo de compra (arredondado para baixo). Por exemplo, você precisa de 750
            GP de matéria-prima para fazer Plate Armor, que é vendido por 1.500 GP. O Mestre determina se a matéria-prima apropriada
            materiais estão disponíveis.


### Tempo

Para determinar quantos dias (trabalhando 8 horas por dia) são necessários para fabricar um item, divida seu custo de compra em GP
            por 10 (arredondar uma fração para um dia). Por exemplo, você precisa de 5 dias para fazer uma Besta Pesada, que é vendida por
            50 GP.

Se um item exigir vários dias, os dias não precisarão ser consecutivos.

Os personagens podem combinar seus esforços para reduzir o tempo de elaboração. Divida o tempo necessário para criar um item
            pelo número de personagens trabalhando nele. Normalmente, apenas um outro personagem pode ajudá-lo, mas o Mestre
            pode permitir mais assistentes.
