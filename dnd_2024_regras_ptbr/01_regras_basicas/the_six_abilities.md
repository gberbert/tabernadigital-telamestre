# Os Seis Atributos (The Six Abilities)

Todas as criaturas – personagens e monstros – possuem seis habilidades que medem características físicas e mentais, como
        mostrado na tabela de Descrições de Habilidades.


###### Descrições de habilidades


| Habilidade | Medidas de pontuação ... |
| --- | --- |
| Força (Strength - FOR) | Poder físico |
| Destreza (Dexterity - DES) | Agilidade, reflexos e equilíbrio |
| Constituição (Constitution - CON) | Saúde e resistência |
| Inteligência (Intelligence - INT) | Raciocínio e memória |
| Sabedoria (Wisdom - SAB) | Perspicácia e fortaleza mental |
| Carisma (Charisma - CAR) | Confiança, equilíbrio e charme |



---


## Pontuações de Habilidade

Cada habilidade tem uma pontuação de 1 a 20, embora alguns monstros tenham uma pontuação de até 30. A pontuação representa
        a magnitude de uma habilidade. A tabela Pontuações de Habilidade resume o significado das pontuações.


###### Pontuações de Habilidade


| Pontuação | Significado |
| --- | --- |
| 1 | Este é o valor mais baixo que uma pontuação normalmente pode atingir. Se um efeito reduzir uma pontuação a 0, esse efeito explica o que acontece. |
| 2–9 | Isto representa uma capacidade fraca. |
| 10–11 | Isso representa a média humana. |
| 12–19 | Isto representa uma forte capacidade. |
| 20 | Esta é a pontuação mais alta que um aventureiro pode atingir, a menos que uma característica diga o contrário. |
| 21–29 | Isto representa uma capacidade extraordinária. |
| 30 | Esta é a pontuação mais alta que uma pontuação pode atingir. |

## Modificadores de habilidade

Cada habilidade tem um modificador que você aplica sempre que faz um Teste D20 com aquela habilidade (explicado em “D20
        Testes”). Um modificador de habilidade é derivado de sua pontuação, conforme mostrado na tabela Modificadores de Habilidade.


###### Modificadores de habilidade


| Pontuação | Modificador |
| --- | --- |
| 1 | −5 |
| 2–3 | −4 |
| 4–5 | −3 |
| 6–7 | −2 |
| 8–9 | −1 |
| 10–11 | +0 |
| 12–13 | +1 |

| 20–21 | +5 |
| 22–23 | +6 |

| 26–27 | +8 |

#### Arredondar para baixo

Sempre que você dividir ou multiplicar um número no jogo, arredonde para baixo se resultar em uma fração, mesmo que a fração seja um meio ou mais. Algumas regras abrem uma exceção e dizem para você arredondar.
