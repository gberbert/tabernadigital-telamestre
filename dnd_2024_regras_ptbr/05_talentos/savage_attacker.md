# Atacante Selvagem

*Talento de Origem*

Você treinou para lidar com ataques particularmente prejudiciais. Uma vez por turno, quando você atingir um alvo com uma arma, você pode rolar os dados de dano da arma duas vezes e usar qualquer uma das jogadas contra o alvo.
