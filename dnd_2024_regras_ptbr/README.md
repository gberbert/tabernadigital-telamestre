## Como utilizar com IA e RAG

1. **RAG (LangChain / LlamaIndex / ChromaDB):** Utilize o fatiador `MarkdownHeaderTextSplitter` configurado para `['#', '##', '###']`. Isso garante que cada regra ou traço de classe seja recuperado com seu cabeçalho de contexto intacto.
2. **Google NotebookLM:** Basta arrastar a pasta `01_regras_basicas/` ou `02_classes/` diretamente para uma nova fonte. As citações apontarão para os artigos exatos.
3. **Claude Projects / OpenAI Custom GPTs:** Suba os arquivos das pastas de regras e classes diretamente como arquivos de conhecimento do projeto.
4. **Consultas Bilíngues:** Os títulos e termos-chave contêm tanto o termo em português quanto em inglês (ex.: *Pontos de Vida (Hit Points - PV)*, *Classe de Armadura (Armor Class - CA)*), permitindo que você pergunte em qualquer um dos dois idiomas.
