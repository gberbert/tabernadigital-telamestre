# Regra: Proibição de Testes Autônomos pelo Agente

1. O agente NÃO deve executar testes no navegador (browser subagents) ou testes manuais de interface por conta própria.
2. Sempre que concluir um desenvolvimento ou modificação, apresente o resumo das alterações e solicite ao USUÁRIO que teste.
3. Testes só poderão ser executados pelo agente se o usuário solicitar de forma textual e explícita na mensagem.
